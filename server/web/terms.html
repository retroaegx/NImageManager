利用規約

制定・施行日：2026年9月3日／規約バージョン：2026-09-03

この利用規約（以下「本規約」）は、NImageManager運営（以下「運営」）が提供する画像管理サービス「NImageManager」（以下「本サービス」）の利用条件を定めるものです。利用者は、本規約およびプライバシーポリシーに同意したうえで本サービスを利用します。

1. アカウント

  1. 利用者は、正確かつ自身が使用できるメールアドレスを登録し、確認手続きを完了する必要があります。
  2. 利用者は、認証情報を自己の責任で管理し、第三者に利用させてはなりません。
  3. 未成年者は、法令上必要となる場合、親権者その他の法定代理人の同意を得て利用してください。
  4. 不正登録、なりすまし、複数アカウントを用いた制限回避その他の不正利用を禁止します。

2. アップロードできるデータ

  1. 利用者は、利用者自身が作成し、かつアップロードおよび本サービスでの利用に必要な権利を利用者自身が保有するデータだけをアップロードできます。
  2. 第三者が著作権、著作隣接権、商標権、肖像権、プライバシー権その他の権利を有する画像・素材・データのアップロードを一切禁止します。
  3. 違法、有害、不正アクセスを目的とするデータ、マルウェアその他本サービスの運営を妨害するデータをアップロードしてはなりません。
  4. 利用者は、アップロードするデータについて必要な権利を有することを保証し、第三者との紛争が生じた場合は自己の責任で解決するものとします。

3. アップロードデータの権利と開発利用

  1. アップロードデータに関する権利は利用者に留保され、運営がその所有権または著作権を取得することはありません。
  2. 運営は、本サービスの不具合調査、動作確認、機能改善、セキュリティ対策および匿名化・集計した統計分析など、NImageManagerの開発および改善に必要な範囲に限り、アップロードデータを閲覧、複製、解析または一時的に加工する場合があります。
  3. 運営は、アップロードデータをAI・機械学習モデルの訓練に使用せず、法令に基づく場合またはサービス提供に必要な委託先を除き、第三者へ提供しません。

4. 共有と一覧サムネイル

  1. 利用者が作品共有を有効にした場合、許可された他の利用者が詳細情報、詳細サムネイルまたは原本を閲覧できることがあります。
  2. 一覧用の低解像度サムネイルは、推測困難な公開URLで配信されます。このURLを知る者は、ログインや作品共有の状態にかかわらず一覧サムネイルへ直接アクセスできる場合があります。
  3. 利用者は、共有設定とアップロード内容を確認したうえで本サービスを利用してください。

5. 禁止事項と利用停止

権利侵害、法令違反、他者への迷惑行為、本サービスへの攻撃・解析・過大な負荷、認証やアクセス制御の回避、虚偽情報の登録を禁止します。運営は、違反またはそのおそれがあると合理的に判断した場合、事前通知なくデータの削除、機能制限またはアカウント停止・削除を行うことがあります。

6. 退会

利用者はログイン後の設定画面から退会できます。退会処理により、その利用者がアップロードした原本、派生画像、サムネイル、メタデータ、ブックマークその他の関連データは削除され、復元できません。法令上の保存義務または障害・不正対応に必要な最小限の記録を除き、運営は削除後の復元を保証しません。
